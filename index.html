Weather that follows the slope

A design study for a phone weather screen. Drag the pin up the mountain and scrub through the day: temperature, cloud, rain and wind all follow the elevation you pick.

This is a web prototype in a phone-shaped frame. It is not an Android app, and every number is sample data from a few written rules, not a forecast.

How the numbers are made

Nothing on the phone is measured. Every figure comes from three plain rules written at the top of app.js, so anyone can read them and argue with them.

  1. −6.5 °C per km up

    Air cools about 6.5 °C for each kilometre of climb, the usual average. The coast follows an invented day curve, 22.5 °C at 02:30 rising to 30.5 °C at 14:30.

  2. 125 m of cloud per °C

    Cloud base sits about 125 m up for every degree between the air temperature and the dew point. The coastal dew point is fixed at 21.5 °C, so the cloud deck rises through the morning and sinks again at night.

  3. 15:30 showers peak

    Rain chance peaks in mid-afternoon and grows with height, a pattern common in tropical highlands. The curve is made up for this study. The green band on the chart is the longest daytime stretch under 25%.

What this is, and what it is not

It is

A design study for one idea: forecast by elevation instead of by town. It is plain HTML, CSS and JavaScript with no build step, one font file, and no network requests for weather.

The sky, the page tint and the chart all react to the same two controls, so the phone behaves like a small instrument rather than a set of screens.

It is not

Not an Android app. There is no Kotlin, Room database, sensor feed or backend here. Not a forecast either, so please do not plan spraying, harvest or travel with it.

Place names are real towns in Northern Mindanao, but their elevations are approximate and the slope between them is a schematic, not a survey line.

History

An earlier version of this repository described itself as an agrometeorology system for Android. It was never that. This rewrite replaces it with what it actually is, and the repository name still carries the old claim.
